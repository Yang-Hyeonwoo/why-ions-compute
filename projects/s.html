P1. 컴퓨터만으로 하는 첫 실험

심장 신호를 거칠게 숫자로 바꾸면 박동을 놓칠까? 기억(memory)은 길수록 좋을까? VS Code에서 코드를 돌리며 내 눈으로 확인합니다

무엇을 하나 VS Code에서 짧은 실습 코드 7개를 하나씩 붙여 넣고 ▷를 누릅니다. 가짜 심장 신호를 만들고(실습 1), 숫자로 바꾸고(2·3), 박동을 찾아 채점하고(4), 기억 과제를 만들어(5) 작은 '기억 모형'에 넣고(6) 맞혀 봅니다(7). 장비·소자는 필요 없습니다.

이 프로젝트를 끝내면 얻는 것 (1) 박동을 하나도 놓치지 않는 가장 작은 설정(숫자 하나). (2) "기억은 길이가 맞아야 쓸모 있다"를 보여 주는 그래프 한 장. 그리고 코드 맨 위 숫자를 바꿔 가며 결과가 어떻게 달라지는지 직접 본 경험.

왜 하나 P2부터는 진짜 소자를 잽니다. 그 전에 "소자 없이 설정만 바꿔도 결과가 이만큼 달라진다"를 숫자로 알아 둬야, 나중에 소자가 한 몫을 가려낼 수 있습니다.

P1.1. 신호를 숫자로 바꿀 때, 어디까지 줄여도 될까

몸에 붙이는 작은 심전도 패치를 떠올려 보세요. 패치는 심장이 만드는 아주 작은 전압을 숫자로 바꿔서 휴대폰으로 보냅니다. 숫자를 많이, 자세히 만들수록 정확하지만 보낼 양이 많아져 전지가 빨리 닳습니다. 그래서 묻습니다. 얼마나 적게, 얼마나 거칠게 만들어도 심장이 뛴 순간을 놓치지 않을까?

P1.1은 이 질문을 네 걸음으로 풉니다.

실습 하는 일 결과로 보는 것
1 가짜 심전도 만들기 심장 신호가 어떻게 생겼나, 정답(박동 시각)
2 sampling rate: 몇 번 집나 점이 듬성하면 봉우리를 놓친다
3 bit: 얼마나 자세히 적나 눈금이 거칠면 작은 물결이 사라진다
4 박동 찾기와 채점 25가지 설정에서 놓친 수 지도

실습 1. 가짜 심전도 만들기 (p1_1_ecg.py)

진짜 환자 기록 대신 수식으로 그린 가짜 심전도를 만듭니다. 가짜를 쓰는 이유는 하나입니다. 심장이 언제 뛰었는지(정답)를 우리가 정확히 알기 때문에, 다음 실습들에서 "박동을 맞게 찾았나"를 채점할 수 있습니다.

심전도는 박동마다 P·Q·R·S·T라는 물결 다섯 개가 이어집니다. 그중 크고 뾰족한 R 봉우리가 "심장이 뛰었다"는 표시이고, 박동 찾기는 이 봉우리를 찾는 일입니다.

할 일 mylabs에 새 파일 p1_1_ecg.py → 아래 코드 붙여 넣기 → Ctrl+S → ▷.

mylabs/p1_1_ecg.py
# ============================================================
# P1 실습 1 · 가짜 심전도(synthetic ECG) 만들고 보기
#
# 전체 과정:
#
#   심장이 뛰는 시각 정하기 (1분에 62–88번)
#         ↓
#   박동마다 P · Q · R · S · T 물결을 더하기
#         ↓
#   숨 쉴 때 흔들리는 기준선 + 작은 noise 더하기
#         ↓
#   그래프로 보기
#
# 이 신호는 진짜 환자 기록이 아니라 수식으로 그린 것입니다.
# 그래서 "심장이 언제 뛰었는지(정답)"를 우리가 정확히 압니다.
# 다음 실습들은 이 정답을 기준으로 채점합니다.
# ============================================================

import numpy as np
import matplotlib.pyplot as plt


# ============================================================
# 0. 그림 설정 (한글 글꼴 · 글씨 크기) — 건드리지 않아도 됩니다
# ============================================================

plt.rcParams.update({
    "font.family": "Malgun Gothic",   # Windows 기본 한글 글꼴
    "axes.unicode_minus": False,      # 마이너스(-)가 깨지지 않게
    "font.size": 11,
    "legend.frameon": False,          # 범례 테두리 없음
    "axes.spines.top": False,
    "axes.spines.right": False,
})


# ============================================================
# 1. 바꿔 볼 수 있는 설정값
# ============================================================

SECONDS = 10      # 신호 길이 (초)
SEED = 1          # 무작위 '씨앗'. 같은 SEED면 언제 돌려도 같은 신호
SHOW_SECONDS = 3  # 그래프에 보여 줄 앞부분 길이 (초)


# 컴퓨터 안에서 "원래 신호"를 그리는 촘촘함.
# 1초에 2000개 점 = 0.5 ms마다 점 하나 → 사람 눈에는 매끈한 곡선.
REF_FS = 2000


# ============================================================
# 2. 심장이 뛰는 시각 정하기
# ============================================================

rng = np.random.default_rng(SEED)

beat_times = []        # 정답: 심장이 뛴 시각 (초)
now = 0.4              # 첫 박동은 0.4초에

while now < SECONDS - 0.6:
    beat_times.append(now)

    # 다음 박동까지의 간격.
    # 1분에 62–88번 뛰므로 간격은 60/88 ≈ 0.68초 ~ 60/62 ≈ 0.97초.
    beats_per_minute = rng.uniform(62, 88)
    now += 60 / beats_per_minute

beat_times = np.array(beat_times)


# ============================================================
# 3. 박동마다 물결 다섯 개(P, Q, R, S, T) 더하기
# ============================================================
#
#   P: 작은 언덕 (심방이 수축)        높이 0.12 mV
#   Q: 작은 골짜기                    -0.12 mV
#   R: 크고 뾰족한 봉우리 (심실 수축)  1.0 mV   ← 박동 찾기에 쓰는 것
#   S: 골짜기                         -0.25 mV
#   T: 넓은 언덕 (회복)               0.3 mV
#
# 물결 하나 = 종 모양(가우스) 곡선.
#   (박동 기준 몇 초 뒤, 높이 mV, 폭 초)
# ============================================================

WAVES = [
    (-0.180,  0.12, 0.025),   # P
    (-0.025, -0.12, 0.008),   # Q
    ( 0.000,  1.00, 0.009),   # R
    ( 0.025, -0.25, 0.009),   # S
    ( 0.280,  0.30, 0.045),   # T
]

t = np.arange(int(SECONDS * REF_FS)) / REF_FS   # 시간 축 (초)
ecg = np.zeros_like(t)                          # 처음엔 0 mV

for b in beat_times:
    for shift, height, width in WAVES:
        ecg += height * np.exp(-0.5 * ((t - b - shift) / width) ** 2)


# ============================================================
# 4. 실제 신호처럼 흔들림 더하기
# ============================================================

# 숨 쉴 때 몸이 움직여 기준선이 천천히 오르내림 (0.3 Hz = 3.3초에 한 번)
ecg += 0.15 * np.sin(2 * np.pi * 0.3 * t)

# 전극·근육에서 오는 작은 noise (표준편차 0.02 mV)
ecg += rng.normal(0, 0.02, t.size)


# ============================================================
# 5. 숫자로 확인
# ============================================================

print("=" * 50)
print("synthetic ECG")
print("=" * 50)
print(f"length          : {SECONDS} s")
print(f"points          : {t.size} (1초에 {REF_FS}개)")
print(f"true beats      : {len(beat_times)}")
print(f"heart rate      : {len(beat_times) / SECONDS * 60:.0f} beats/min")
print(f"first 3 beats   : {np.round(beat_times[:3], 3)} s")
print(f"min / max value : {ecg.min():.2f} / {ecg.max():.2f} mV")


# ============================================================
# 6. 그래프: 앞부분 SHOW_SECONDS초
# ============================================================

show = t < SHOW_SECONDS

fig, ax = plt.subplots(figsize=(8, 3.6))
ax.plot(t[show], ecg[show], color="0.35", lw=1.2, label="synthetic ECG")

# 정답 박동 시각에 빨간 ▼ (R 봉우리 위)
b_show = beat_times[beat_times < SHOW_SECONDS]
ax.plot(b_show, np.full(len(b_show), 1.25), "v", color="#c0392b", ms=8,
        label="정답: 심장이 뛴 시각")

# 첫 박동의 물결 이름 붙이기

실습 2. sampling rate: 1초에 몇 번 값을 집을까 (p1_2_sampling.py)

컴퓨터는 신호를 연속으로 보지 못합니다. 일정한 간격마다 그 순간의 값을 하나씩 집어서 숫자로 적습니다. 1초에 몇 번 집는지가 sampling rate입니다. 생각하신 대로, 25 Hz는 1초에 25번, 곧 40 ms마다 한 번 값을 집습니다.

이 실습은 집는 간격이 넓으면 실습 1의 바늘 같은 R 봉우리를 건너뛰어 버리는지를 그림으로 봅니다.

sampling rate (단위 Hz): 1초에 값을 몇 번 집는지. 100 Hz = 1초에 100번 = 10 ms마다 한 번. 집은 값 하나를 sample이라고 합니다.

# ============================================================
# P1 실습 2 · sampling rate: 1초에 몇 번 값을 집을까
#
# 전체 과정:
#
#   실습 1과 같은 가짜 심전도 (원래 신호, 1초에 2000점)
#         ↓
#   FS Hz로 값 집기  = 1/FS 초마다 점 하나만 남기기
#         ↓
#   R 봉우리(박동)마다 "기준선보다 0.5 mV 높은 선 위에 점이 찍혔나?" 세기
#         ↓
#   그래프: 매끈한 원래 신호 vs 컴퓨터가 가진 점들
#
# 맨 위의 FS 숫자를 바꿔 다시 Run 해 보는 것이 이 실습의 핵심입니다.
# ============================================================

import numpy as np
import matplotlib.pyplot as plt


# ============================================================
# 0. 그림 설정 — 건드리지 않아도 됩니다
# ============================================================

plt.rcParams.update({
    "font.family": "Malgun Gothic", "axes.unicode_minus": False, "font.size": 11,
    "legend.frameon": False, "axes.spines.top": False, "axes.spines.right": False,
})


# ============================================================
# 1. 바꿔 볼 수 있는 설정값  ← 여기를 바꿔 보세요
# ============================================================

FS = 25            # sampling rate (Hz): 1초에 값을 몇 번 집나. 25, 50, 100, 250, 500 …
THRESHOLD = 0.5    # 박동 판정 선: 봉우리 앞 기준선보다 몇 mV 높아야 하나. 실습 4에서 자세히
SECONDS = 60       # 신호 길이 (초)
SEED = 1


# ============================================================
# 2. 가짜 심전도 만들기 (실습 1과 같은 코드)
# ============================================================

REF_FS = 2000      # 원래 신호의 촘촘함: 1초에 2000점

def make_ecg(seconds, seed):
    """가짜 심전도(mV)와 정답 박동 시각(초)을 돌려준다."""
    rng = np.random.default_rng(seed)
    beats, now = [], 0.4
    while now < seconds - 0.6:
        beats.append(now)
        now += 60 / rng.uniform(62, 88)
    t = np.arange(int(seconds * REF_FS)) / REF_FS
    x = np.zeros_like(t)
    for b in beats:
        for shift, height, width in [(-0.18, 0.12, 0.025), (-0.025, -0.12, 0.008), (0, 1.0, 0.009),
                                     (0.025, -0.25, 0.009), (0.28, 0.3, 0.045)]:
            x += height * np.exp(-0.5 * ((t - b - shift) / width) ** 2)
    x += 0.15 * np.sin(2 * np.pi * 0.3 * t) + rng.normal(0, 0.02, t.size)
    return t, x, np.array(beats)

t, ecg, beats = make_ecg(SECONDS, SEED)


# ============================================================
# 3. FS Hz로 값 집기 (sampling)
# ============================================================
#
# 원래 신호는 0.5 ms마다 점이 있다 (2000 Hz).
# FS = 25 Hz면 2000 / 25 = 80칸마다 하나만 남긴다
#   → 40 ms마다 점 하나.
# ============================================================

if REF_FS % FS != 0:
    raise SystemExit(f"FS = {FS}: 2000을 나누어떨어지게 하는 수만 됩니다 (25, 40, 50, 80, 100, 125, 200, 250, 400, 500 …)")

step = REF_FS // FS
ts = t[::step]          # 집은 순간의 시각
xs = ecg[::step]        # 집은 값

interval_ms = 1000 / FS


# ============================================================
# 4. 박동마다: R 봉우리 근처(±30 ms)에 "기준선 + 0.5 mV" 선을 넘는 점이 있나?
# ============================================================
#
# 기준선이 흔들리므로, 봉우리 바로 앞 0.2초의 평균을 빼고 본다.
# (실습 4의 박동 찾기와 같은 방식)
# ============================================================

caught = 0
caught_flag = []                                          # 박동마다 잡았나(True) 놓쳤나(False)
for b in beats:
    near = np.abs(ts - b) <= 0.03                        # 봉우리 ±30 ms 안의 점들
    base = xs[(ts > b - 0.25) & (ts < b - 0.05)]          # 봉우리 앞 기준선
    base = base.mean() if len(base) else 0
    ok = bool(near.any() and (xs[near] - base).max() > THRESHOLD)
    caught_flag.append(ok)
    caught += ok

print("=" * 50)
print(f"sampling rate {FS} Hz")
print("=" * 50)
print(f"interval between samples : {interval_ms:.0f} ms")
print(f"samples in {SECONDS} s           : {len(xs)}")
print(f"true beats               : {len(beats)}")
print(f"beats with a sample above baseline + {THRESHOLD} mV : {caught} / {len(beats)}")
print(f"beats missed by sampling : {len(beats) - caught}")


# ============================================================
# 5. 그래프: "잡은 박동" 하나와 "놓친 박동" 하나를 크게
# ============================================================
#
# 놓친 박동이 없으면(FS가 충분히 높으면) 처음 두 박동을 보여 준다.
# ============================================================

caught_flag = np.array(caught_flag)
pick = []
if caught_flag.any():
    pick.append((beats[caught_flag][0], "잡은 박동 (예)"))
if (~caught_flag).any():
    pick.append((beats[~caught_flag][0], "놓친 박동 (예)"))
while len(pick) < 2:
    pick.append((beats[len(pick)], "잡은 박동 (예)"))

fig, axs = plt.subplots(1, 2, figsize=(8, 3.6), sharey=True)

for ax, (b, title) in zip(axs, pick):
    lo, hi = b - 0.15, b + 0.15                 # 봉우리 앞뒤 0.15초
    m = (t >= lo) & (t <= hi)
    ms = (ts >= lo) & (ts <= hi)

    # 판정 선: 봉우리 앞 기준선 + THRESHOLD. 파란 점이 이 선을 넘어야 '박동'으로 잡힌다
    base_b = ecg[(t > b - 0.25) & (t < b - 0.05)].mean()
    ax.axhline(base_b + THRESHOLD, color="#d9962a", ls="--", lw=1.3, label=f"판정 선 (기준선 + {THRESHOLD} mV)")
    ax.plot((t[m] - b) * 1000, ecg[m], color="0.75", lw=2, label="원래 신호")
    ax.vlines((ts[ms] - b) * 1000, -0.4, xs[ms], color="#2b59c3", lw=1)
    ax.plot((ts[ms] - b) * 1000, xs[ms], "o", color="#2b59c3", ms=5, label=f"집은 값 ({FS} Hz)")
    ax.set_xlabel("R 봉우리 기준 시간 (ms)")
    ax.set_ylim(-0.4, 1.3)
    ax.set_title(title, loc="left")

axs[0].set_ylabel("mV")
fig.suptitle(f"{FS} Hz = {interval_ms:.0f} ms마다 점 하나: 봉우리를 집었나?", x=0.02, ha="left", fontsize=12)
fig.tight_layout(rect=(0, 0.08, 1, 1))
# 범례는 그래프 아래 한 줄에 (그래프·제목과 겹치지 않게)
fig.legend(*axs[0].get_legend_handles_labels(), loc="lower center", ncol=3, bbox_to_anchor=(0.5, 0.0))

실습 3. bit: 집은 값을 얼마나 자세히 적을까 (p1_3_bits.py)

집은 값은 눈금자에 대고 읽는 것과 같습니다. 눈금이 8개뿐인 자로 재면 0.37 mV가 "0.5 mV쯤"으로 적히고, 눈금이 4,096개인 자로 재면 "0.370 mV"로 적힙니다. bit는 이 자에 눈금이 몇 개 있는지를 정합니다.

이 실습은 sampling rate는 넉넉히(500 Hz) 고정해 두고 bit만 바꿔서, 거친 눈금이 작은 물결(P wave)을 지워 버리는지 봅니다.

왜 "bit"라고 부를까. 컴퓨터는 숫자를 0과 1로만 적습니다. 0 또는 1 한 자리가 bit 하나입니다. 3자리(3 bit)로 적을 수 있는 숫자는 000, 001, 010, … , 111의 8가지(2×2×2)뿐이라 눈금도 8칸입니다. 12 bit면 2를 12번 곱한 4,096가지입니다.

bit: 숫자 하나를 0과 1 몇 자리로 적는지. 눈금 수 = 2bit. 3 bit = 8칸, 12 bit = 4,096칸.

LSB (Least Significant Bit, 가장 낮은 자리 bit): 눈금 한 칸의 크기. 이 코드는 −2 mV부터 +2 mV까지 폭 4 mV를 나누므로 LSB = 4 mV ÷ 눈금 수. 3 bit면 4 ÷ 8 = 0.5 mV = 500 µV, 12 bit면 4 ÷ 4,096 ≈ 0.001 mV = 1 µV(µV = mV의 1,000분의 1). "12 bit에서 한 눈금이 1 µV"라는 말은 이 계산이고, sampling rate와는 상관없습니다.

# ============================================================
# P1 실습 3 · bit: 집은 값을 얼마나 자세히 적을까
#
# 전체 과정:
#
#   가짜 심전도를 촘촘하게(500 Hz) 집기   ← 여기서는 sampling rate 걱정 없이
#         ↓
#   −2 mV ~ +2 mV를 눈금 2^BITS칸으로 나눈 '자' 만들기
#         ↓
#   집은 값을 가장 가까운 눈금으로 반올림 (= 숫자로 적기)
#         ↓
#   그래프: 원래 신호 vs 계단 모양으로 적힌 값
#           특히 작은 물결(P wave, 0.12 mV)이 살아남나?
#
# 맨 위의 BITS 숫자를 3 → 4 → 6 → 12로 바꿔 Run 해 보세요.
# ============================================================

import numpy as np
import matplotlib.pyplot as plt


# ============================================================
# 0. 그림 설정 — 건드리지 않아도 됩니다
# ============================================================

plt.rcParams.update({
    "font.family": "Malgun Gothic", "axes.unicode_minus": False, "font.size": 11,
    "legend.frameon": False, "axes.spines.top": False, "axes.spines.right": False,
})


# ============================================================
# 1. 바꿔 볼 수 있는 설정값  ← 여기를 바꿔 보세요
# ============================================================

BITS = 3            # 숫자 하나를 0과 1 몇 자리로 적나. 3, 4, 6, 8, 12 …
FS = 500            # sampling rate는 넉넉하게 고정 (bit 효과만 보려고)
RANGE_MV = 2.0      # 자의 범위: −2 mV ~ +2 mV (폭 4 mV)
SEED = 1


# ============================================================
# 2. 가짜 심전도 만들기 (실습 1·2와 같은 코드)
# ============================================================

REF_FS = 2000

def make_ecg(seconds, seed):
    """가짜 심전도(mV)와 정답 박동 시각(초)을 돌려준다."""
    rng = np.random.default_rng(seed)
    beats, now = [], 0.4
    while now < seconds - 0.6:
        beats.append(now)
        now += 60 / rng.uniform(62, 88)
    t = np.arange(int(seconds * REF_FS)) / REF_FS
    x = np.zeros_like(t)
    for b in beats:
        for shift, height, width in [(-0.18, 0.12, 0.025), (-0.025, -0.12, 0.008), (0, 1.0, 0.009),
                                     (0.025, -0.25, 0.009), (0.28, 0.3, 0.045)]:
            x += height * np.exp(-0.5 * ((t - b - shift) / width) ** 2)
    x += 0.15 * np.sin(2 * np.pi * 0.3 * t) + rng.normal(0, 0.02, t.size)
    return t, x, np.array(beats)

t, ecg, beats = make_ecg(5, SEED)

step = REF_FS // FS
ts, xs = t[::step], ecg[::step]          # 500 Hz로 집은 값


# ============================================================
# 3. '자' 만들기: 눈금 수와 눈금 한 칸(LSB)
# ============================================================
#
#   bit 하나 = 0 또는 1, 두 가지
#   BITS자리  = 2 × 2 × … (BITS번) = 2^BITS 가지 숫자
#   → 폭 4 mV를 2^BITS칸으로 나눈다
#
#   LSB (Least Significant Bit) = 눈금 한 칸의 크기
# ============================================================

levels = 2 ** BITS
lsb = 2 * RANGE_MV / levels               # mV


# ============================================================
# 4. 반올림해서 적기 (quantization)
# ============================================================
#
#   값 ÷ LSB → 가장 가까운 정수로 반올림 → 다시 × LSB
#   예) 3 bit, LSB 0.5 mV:  0.37 mV → 0.74 → 1 → 0.5 mV
#   자의 범위를 넘는 값은 끝 눈금에 붙는다 (clip)
# ============================================================

code = np.round(xs / lsb)

실습 4. 박동 찾기와 채점: 어디까지 줄여도 될까 (p1_4_detect.py)

실습 2(몇 번 집나)와 실습 3(얼마나 자세히 적나)을 합쳐서, 숫자로 바뀐 신호에서 박동을 찾고 정답과 비교해 채점합니다. 그리고 sampling rate 5가지 × bit 5가지 = 25가지 설정을 한꺼번에 채점해 지도로 그립니다. 이 지도가 P1.1의 최종 결과입니다.

박동 찾는 법: threshold. 프로그램은 가장 단순한 방법을 씁니다. 값이 기준선보다 정해 둔 만큼(0.5 mV) 넘게 솟으면 박동입니다. 심장이 뛸 때만 신호가 크게 솟기 때문에, 솟은 순간을 잡으면 박동을 찾을 수 있습니다.

threshold: "이 값을 넘으면 사건이 일어났다"고 정해 둔 선. 여기서는 기준선보다 0.5 mV 높은 곳.

miss와 false+: 반대 방향의 실수입니다. miss는 있는 것을 못 본 실수(박동이 있었는데 못 찾음), false+(false positive)는 없는 것을 봤다고 한 실수(박동이 아닌 잡음을 박동이라고 함).

timing error: 박동을 찾았지만 그 시각이 정답과 평균 몇 ms 어긋났는지. 점이 듬성하면 꼭대기를 정확히 못 집으니 커집니다.

data rate (bit/s): sampling rate × bit. 1초에 만드는 0과 1의 개수. 100 Hz × 4 bit = 400 bit/s. 작을수록 보낼 것이 적어 전지가 오래 갑니다.

# P1 실습 4 · 박동 찾기와 채점: 어디까지 줄여도 될까
#
# 전체 과정:
#
#   가짜 심전도 60초 (정답 박동 74개)
#         ↓
#   FS Hz로 집고, BITS bit로 적기 (실습 2 + 실습 3)
#         ↓
#   박동 찾기: 기준선을 빼고, THRESHOLD 선을 넘으면 '박동'
#         ↓
#   정답과 비교: hit · miss · false+ · timing error
#         ↓
#   [그림 1] FS·BITS 한 가지 설정의 판정 결과 (4초 구간)

# 1. 바꿔 볼 수 있는 설정값  ← 여기를 바꿔 보세요
# ============================================================

FS = 25             # sampling rate (Hz)
BITS = 3            # bit
THRESHOLD = 0.5     # 판정 선 (mV): 기준선보다 이만큼 높으면 박동
SECONDS = 60
SEED = 1

# 그림 2에서 한꺼번에 볼 설정들
FS_LIST = [25, 50, 100, 250, 500]

# ============================================================
# 2. 가짜 심전도 · 집기 · 적기 (실습 1–3과 같은 코드)
# ============================================================

REF_FS = 2000

def make_ecg(seconds, seed):
    rng = np.random.default_rng(seed)
    beats, now = [], 0.4
    while now < seconds - 0.6:
        beats.append(now)
        now += 60 / rng.uniform(62, 88)
    t = np.arange(int(seconds * REF_FS)) / REF_FS
    x = np.zeros_like(t)
    for b in beats:
        for shift, height, width in [(-0.18, 0.12, 0.025), (-0.025, -0.12, 0.008), (0, 1.0, 0.009),
                                     (0.025, -0.25, 0.009), (0.28, 0.3, 0.045)]:
            x += height * np.exp(-0.5 * ((t - b - shift) / width) ** 2)
    x += 0.15 * np.sin(2 * np.pi * 0.3 * t) + rng.normal(0, 0.02, t.size)
    return t, x, np.array(beats)


def digitize(t, x, fs, bits, range_mv=2.0):
    """fs Hz로 집고 bits bit로 반올림해 적는다."""
    step = REF_FS // fs
    ts, xs = t[::step], x[::step]
    lsb = 2 * range_mv / 2 ** bits
    code = np.clip(np.round(xs / lsb), -(2 ** (bits - 1)), 2 ** (bits - 1) - 1)
    return ts, code * lsb


# ============================================================
# 3. 박동 찾기 (detection)
# ============================================================
#
#   ① 기준선 빼기: 0.2초 동안의 평균(= 천천히 흔들리는 기준선)을 뺀다
#   ② 값이 THRESHOLD를 넘으면 → 거기서부터 오르막이 끝나는 꼭대기를 '박동 시각'으로
#   ③ 한 번 찾으면 0.25초 동안은 다시 찾지 않는다
#      (심장은 0.25초 안에 두 번 뛰지 못하므로. 이것을 refractory period라고 함)
# ============================================================

def detect(ts, xq, fs, threshold):
    k = max(1, int(round(0.2 * fs)))
    baseline = np.convolve(xq, np.ones(k) / k, mode="same")     # ① 0.2초 이동평균
    y = xq - baseline
    found, i = [], 0
    while i < len(y):
        if y[i] > threshold:                                     # ② 선을 넘음
            j = i
            while j + 1 < len(y) and y[j + 1] >= y[j]:          #    꼭대기까지 올라가기
                j += 1
            found.append(ts[j])
            i = j + max(1, int(0.25 * fs))                       # ③ 0.25초 쉬기
        else:
            i += 1
    return np.array(found)


# ============================================================
# 4. 채점 (정답과 비교)
# ============================================================
#
#   정답 박동마다 ±50 ms 안에 찾은 박동이 있으면 hit (짝을 지음)
#   짝이 없으면 miss (있는데 못 찾음)
#   짝을 못 지은 찾은 박동은 false+ (없는데 있다고 함)
#   hit의 시각 차이 평균 = timing error
# ============================================================

def score(found, truth, tol=0.05):
    used = np.zeros(len(found), bool)
    hits, errors, missed = [], [], []
    for b in truth:
        d = np.abs(found - b)
        cand = np.where((d <= tol) & ~used)[0]
        if len(cand):
            j = cand[np.argmin(d[cand])]
            used[j] = True
            hits.append(found[j])
            errors.append(abs(found[j] - b))
        else:
            missed.append(b)
    false_pos = found[~used]
    err_ms = 1000 * np.mean(errors) if errors else float("nan")
    return np.array(hits), np.array(missed), false_pos, err_ms


# ============================================================
# 5. 한 가지 설정 (FS, BITS)로 돌리기
# ============================================================

t, ecg, beats = make_ecg(SECONDS, SEED)
ts, xq = digitize(t, ecg, FS, BITS)
found = detect(ts, xq, FS, THRESHOLD)
hits, missed, false_pos, err_ms = score(found, beats)

print("=" * 50)
print(f"{FS} Hz x {BITS} bit  (data rate {FS * BITS} bit/s)")
print("=" * 50)
print(f"true beats    : {len(beats)}")
print(f"hit           : {len(hits)}")
print(f"miss          : {len(missed)}")
print(f"false+        : {len(false_pos)}")
print(f"timing error  : {err_ms:.1f} ms")

관찰 적기 (완료 조건)

할 일 연구 노트(새 탭으로 열림)나 메모장에 아래 두 질문의 답을 먼저 내 말로 적고, 그다음 "정답 보기"를 눌러 비교합니다.

질문 1. miss가 0이 되는 가장 작은 data rate는? ______ bit/s (설정: ___ Hz × ___ bit)

400 bit/s (100 Hz × 4 bit). 그림 8에서 0인 칸 중 data rate가 가장 작은 칸입니다. 바로 왼쪽 100 Hz × 3 bit(300 bit/s)는 1개를 놓칩니다.

질문 2. 25 Hz에서는 bit를 12까지 올려도 miss가 48개나 됩니다. 왜 bit를 올려도 소용이 없을까요? 힌트: 그림 2와 그림 4를 나란히 봅니다.

25 Hz는 40 ms마다 한 번만 값을 집는데, R 봉우리가 판정 선 위에 있는 시간은 약 20 ms뿐입니다. 그래서 박동의 절반 넘게 점이 그 20 ms를 비켜 가고, 컴퓨터가 가진 숫자에는 봉우리가 아예 없습니다(그림 2 오른쪽).

bit는 집은 값을 얼마나 자세히 적느냐입니다(그림 4). 봉우리 옆의 낮은 값을 아무리 자세히 적어도 낮은 값일 뿐입니다. 집지 못한 순간은 자세히 적을 수도 없습니다.

관찰할 점: "무엇을 알아내려 하느냐"가 설정을 정한다. 이 결론은 "박동이 있었나"만 묻기 때문에 나왔습니다. 만약 같은 신호에서 P wave 모양(높이 0.12 mV)까지 보고 싶다면, 실습 3에서 본 것처럼 4 bit의 눈금(250 µV)으로는 P wave가 뭉개집니다. 그때는 bit를 더 올려야 합니다. 정리하면,

하고 싶은 일 필요한 것 예
심박수만 세기 (박동이 있었나) 봉우리를 놓치지 않는 sampling rate 100 Hz × 4 bit = 400 bit/s로 충분
심전도 모양 보기 (P wave까지) 작은 물결이 눈금 여러 칸이 되는 bit 같은 100 Hz라도 12 bit = 1,200 bit/s

그래서 data rate가 작다는 이유만으로 설정을 고르면 안 되고, 먼저 무엇을 판정할지 정해야 합니다.

P1.2. 기억은 길수록 좋을까

이온 소자를 공부하면 "기억(memory)이 있다"는 말을 자주 봅니다. 앞에 들어온 입력의 흔적이 지금 상태에 남는다는 뜻입니다. P1.2는 이 질문 하나를 봅니다. 흔적이 오래 남을수록 좋을까?

머그컵으로 생각해 보기. 뜨거운 물을 부었다가 버린 머그컵은 한동안 따뜻합니다. 그래서 지금 컵을 만져 보면 "조금 전에 뜨거운 물이 있었구나"를 알 수 있습니다. 컵이 얇은 종이컵이면 금방 식어서 1분만 지나도 알 수 없습니다. 반대로 두꺼운 뚝배기는 하루 종일 미지근해서, 오늘 아침에 부었는지 방금 부었는지 구별이 안 됩니다. 컵의 두께(흔적이 남는 시간)가 알맞아야 "언제 부었는지"를 맞힐 수 있습니다.

# ============================================================
# P1 실습 5 · 기억 과제 만들기: pattern 0과 pattern 1
#
# 전체 과정:
#
#   12칸짜리 입력 한 줄 = trial 하나
#         ↓
#   pattern 0: 큰 입력(1) 3번이 앞쪽 4칸(0–3) 안에
#   pattern 1: 큰 입력(1) 3번이 가운데 4칸(4–7) 안에
#   나머지 칸: 작은 입력(0.1) + 모든 칸에 작은 흔들림(noise)
#         ↓
#   trial 200개 (pattern마다 100개)
#         ↓
#   그래프: 예시 몇 개 + 칸마다 평균
#
# 핵심: 마지막 4칸(8–11, readout 구간)은 두 pattern의 입력이 똑같다.
#       그래서 '마지막 4칸의 입력'만 보면 어느 pattern인지 모른다.

import numpy as np
import matplotlib.pyplot as plt


# ============================================================
# 0. 그림 설정 — 건드리지 않아도 됩니다
# ============================================================

plt.rcParams.update({
    "font.family": "Malgun Gothic", "axes.unicode_minus": False, "font.size": 11,
    "legend.frameon": False, "axes.spines.top": False, "axes.spines.right": False,
})


# ============================================================
# 1. 설정값
# ============================================================

N_TRIALS = 200      # 시험 문제 수 (짝수)
N_STEPS = 12        # 한 trial의 칸 수 (time step)
NOISE = 0.03        # 모든 칸에 더하는 작은 흔들림의 크기
SEED = 1


# ============================================================
# 2. trial 만들기
# ============================================================

def make_task(n, seed):
    """입력 U (n × 12)와 정답 y (0 또는 1)를 돌려준다."""
    rng = np.random.default_rng(seed)

    U = np.full((n, N_STEPS), 0.1)       # 처음엔 모든 칸이 작은 입력 0.1
    y = np.arange(n) % 2                 # 정답: 0, 1, 0, 1, … (반반)

    U += rng.normal(0, NOISE, U.shape)   # 흔들림
    return U, y

U, y = make_task(N_TRIALS, SEED)

실습 6. R–C 하나에 넣어 보기: 흔적이 남을까 (p1_6_rc.py)

실습 5의 입력을 R–C 라는 가장 단순한 기억 모형에 한 칸씩 넣고, 칸마다 모형의 state(머그컵의 지금 온도)를 그립니다. 그리고 흔적이 남는 시간 τ를 바꿔 가며, 마지막 4칸에서 두 pattern의 state가 벌어지는지 봅니다. 벌어지면 다음 실습에서 맞힐 수 있습니다.

R–C: 저항(R, resistor)과 capacitor(C, 전기를 담는 부품) 하나씩으로 된 가장 단순한 회로. capacitor는 물통처럼 전기를 채웠다가 저항을 통해 천천히 내보내므로, 입력이 지나간 뒤에도 잠시 값이 남습니다. 이온 소자의 "흔적"을 가장 단순하게 흉내 낸 모형이라 기준으로 씁니다.

state: 모형이 지금 들고 있는 값(머그컵의 지금 온도). 입력이 들어올 때마다 바뀝니다.

time constant τ (타우): 흔적이 얼마나 오래 남는지(단위: 칸). 컵의 두께. 그림 11처럼 τ = 0.3칸은 바로 사라지고, τ = 3칸은 몇 칸 동안 남고, τ = 100칸은 아주 조금 오르고 오래 남습니다.

# ============================================================
# P1 실습 6 · R–C 하나에 넣어 보기: 흔적이 남을까
#
# 전체 과정:
#
#   실습 5와 같은 trial 200개
#         ↓
#   R–C 하나에 한 칸씩 차례로 넣기
#       state(다음) = a × state(지금) + (1 − a) × 입력
#       a = e^(−1/TAU)   ← TAU가 클수록 a가 1에 가까워 천천히 변함
#         ↓
#   그래프: 입력 막대 위에 state 곡선
#           pattern 0과 1의 평균 state가 readout 구간(8–11)에서 벌어지나?
#
# 맨 위의 TAU를 0.3 → 3 → 100으로 바꿔 Run 해 보세요.
# ============================================================

import numpy as np
import matplotlib.pyplot as plt


# ============================================================
# 0. 그림 설정 — 건드리지 않아도 됩니다
# ============================================================

plt.rcParams.update({
    "font.family": "Malgun Gothic", "axes.unicode_minus": False, "font.size": 11,
    "legend.frameon": False, "axes.spines.top": False, "axes.spines.right": False,
})


# ============================================================
# 1. 바꿔 볼 수 있는 설정값  ← 여기를 바꿔 보세요
# ============================================================

TAU = 3.0           # time constant τ (칸). 흔적이 얼마나 오래 남나. 0.3, 1, 3, 10, 100 …
N_TRIALS = 200
SEED = 1


# ============================================================
# 2. trial 만들기 (실습 5와 같은 코드)
# ============================================================

def make_task(n, seed, n_steps=12, noise=0.03):
    rng = np.random.default_rng(seed)
    U = np.full((n, n_steps), 0.1)
    y = np.arange(n) % 2
    rng.shuffle(y)
    for i in range(n):
        start = 0 if y[i] == 0 else 4
        U[i, start + rng.choice(4, 3, replace=False)] = 1.0
    U += rng.normal(0, noise, U.shape)
    return U, y

U, y = make_task(N_TRIALS, SEED)


# ============================================================
# 3. R–C 하나 (머그컵 하나)
# ============================================================
#
#   매 칸마다:
#     state = a × (지난 state) + (1 − a) × (지금 입력)
#
#   a가 1에 가까우면 (TAU 큼): 지난 state를 거의 그대로 들고 감 → 천천히 변함
#   a가 0에 가까우면 (TAU 작음): 지난 state를 거의 버림 → 지금 입력만 따라감
#
#   TAU = 3이면 a = e^(−1/3) ≈ 0.72 : 한 칸 지날 때마다 흔적의 72%가 남음
# ============================================================

def run_rc(U, tau):
    a = np.exp(-1.0 / tau)
    X = np.zeros_like(U)                  # 칸마다의 state를 모아 둘 곳
    state = np.zeros(len(U))              # 처음 state = 0 (모든 trial 동시에 계산)
    for k in range(U.shape[1]):           # 0칸, 1칸, … 11칸 차례로
        state = a * state + (1 - a) * U[:, k]
        X[:, k] = state
    return X

X = run_rc(U, TAU)


# ============================================================
# 4. 숫자로 확인: readout 구간에서 두 pattern의 state 차이
# ============================================================

end = slice(8, 12)
s0 = X[y == 0][:, end].mean()
s1 = X[y == 1][:, end].mean()

print("=" * 50)
print(f"R-C, tau = {TAU:g} steps   (a = {np.exp(-1 / TAU):.3f})")
print("=" * 50)
print("mean state in the readout steps (8-11):")
print(f"   pattern 0          : {s0:.4f}")
print(f"   pattern 1          : {s1:.4f}")
print(f"   difference (1 - 0) : {s1 - s0:+.4f}")
print(f"   difference / size  : {(s1 - s0) / max(abs(s0), abs(s1)):.0%}")


# ============================================================
# 5. 그래프: 위 = trial 하나씩 (입력 막대 + state 선), 아래 = 평균 state
# ============================================================

fig = plt.figure(figsize=(8, 6.0))
gs = fig.add_gridspec(2, 2, height_ratios=[1, 1.15], hspace=0.6, wspace=0.25)

for col, c in enumerate((0, 1)):
    i = np.where(y == c)[0][0]
    ax = fig.add_subplot(gs[0, col])
    ax.axvspan(7.5, 11.5, color="#fff1d3", zorder=0)
    ax.bar(range(12), U[i], color="#c9d3ea", width=0.75, label="입력")
    ax.plot(range(12), X[i], "o-", color="#c0521c", lw=2, ms=4, label="state")
    ax.set_ylim(0, 1.15)
    ax.set_xticks([0, 4, 8, 11])
    ax.set_title(f"pattern {c}의 trial 하나", loc="left", fontsize=10.5)
    if col == 0:
        ax.legend(loc="upper right")

ax = fig.add_subplot(gs[1, :])
ax.axvspan(7.5, 11.5, color="#fff1d3", zorder=0, label="readout 구간")
m0, m1 = X[y == 0].mean(0), X[y == 1].mean(0)
ax.plot(range(12), m0, "o-", color="#2b59c3", label="pattern 0 평균 state")
ax.plot(range(12), m1, "s--", color="#c0521c", label="pattern 1 평균 state")
ax.set_ylim(0, max(m0.max(), m1.max()) * 1.15)
ax.set_xticks(range(12))
ax.set_xlabel("time step (칸)")
ax.set_ylabel("state")
ax.set_title(f"τ = {TAU:g}칸: 노란 구간에서 두 선이 얼마나 벌어졌나", loc="left")
ax.legend(loc="upper center", ncol=3, bbox_to_anchor=(0.5, -0.32))

plt.show()

실습 7. readout 채점: 마지막 4칸만 보고 맞힐 수 있나 (p1_7_readout.py)

실습 6에서 눈으로 본 "벌어짐"을 숫자(맞힌 비율)로 바꿉니다. 마지막 4칸의 state만 보고 pattern을 맞히는 규칙(readout)을 연습 문제로 정하고, 처음 보는 시험 문제로 채점합니다. 이것을 τ 다섯 개에 대해 반복해서, τ에 따른 맞힌 비율을 한 장의 그래프로 그립니다. 이 그래프가 P1.2의 최종 결과입니다.

readout: state를 읽어서 답을 내는 일. 여기서는 "마지막 4칸 state에 각각 무게(weight)를 곱해 더한 값이 0보다 크면 pattern 1". 무게는 연습 문제의 정답에 가장 잘 맞도록 컴퓨터가 정합니다.

balanced accuracy: 맞힌 비율. 단, pattern 0 문제와 pattern 1 문제를 따로 채점해서 평균을 냅니다. 예: pattern 0은 100개 중 90개, pattern 1은 100개 중 98개 맞히면 (0.90 + 0.98) ÷ 2 = 0.94. 따로 채점하면, 한쪽 답만 계속 찍는 꼼수가 1.0과 0.0의 평균 0.5로 들통납니다.

chance: 아무 생각 없이 찍을 때의 점수. 답이 둘이니 0.50. 0.50 근처 = 못 맞힌다, 1.00 = 다 맞힌다.

# ============================================================
# P1 실습 7 · readout 채점: 마지막 4칸 state만 보고 맞힐 수 있나
#
# 전체 과정:
#
#   실습 5의 trial 200개 → 실습 6의 R–C에 넣기 (τ 하나)
#         ↓
#   마지막 4칸(8–11)의 state 4개만 꺼내기
#   + 측정기 오차(readout noise) 더하기
#         ↓
#   readout = "state 4개에 무게를 곱해 더한 값이 0보다 크면 pattern 1"
#   무게(weight)는 연습 문제로 정한다 (선형 분류, ridge)
#         ↓
#   5-fold cross-validation: 연습 160개 / 시험 40개를 다섯 번 바꿔 가며
#         ↓
#   balanced accuracy (맞힌 비율) + label shuffle (정답지 섞기 점검)
#         ↓
#   τ를 여러 개로 반복  →  [그림] τ에 따른 맞힌 비율 (산 모양?)
# ============================================================

import numpy as np
import matplotlib.pyplot as plt


# ============================================================
# 0. 그림 설정 — 건드리지 않아도 됩니다
# ============================================================

plt.rcParams.update({
    "font.family": "Malgun Gothic", "axes.unicode_minus": False, "font.size": 11,
    "legend.frameon": False, "axes.spines.top": False, "axes.spines.right": False,
})


# ============================================================
# 1. 바꿔 볼 수 있는 설정값  ← 여기를 바꿔 보세요
# ============================================================

TAUS = [0.3, 1, 3, 10, 100]   # 비교할 τ 목록 (칸)
NOISE = 0.01                  # readout noise: state를 읽을 때 생기는 오차의 크기
N_TRIALS = 200
SEED = 1


# ============================================================
# 2. trial 만들기 · R–C (실습 5·6과 같은 코드)
# ============================================================

def make_task(n, seed, n_steps=12, noise=0.03):
    rng = np.random.default_rng(seed)
    U = np.full((n, n_steps), 0.1)
    y = np.arange(n) % 2
    rng.shuffle(y)
    for i in range(n):
        start = 0 if y[i] == 0 else 4
        U[i, start + rng.choice(4, 3, replace=False)] = 1.0
    U += rng.normal(0, noise, U.shape)
    return U, y


def run_rc(U, tau):
    a = np.exp(-1.0 / tau)
    X = np.zeros_like(U)
    state = np.zeros(len(U))
    for k in range(U.shape[1]):
        state = a * state + (1 - a) * U[:, k]
        X[:, k] = state
    return X


# ============================================================
# 3. readout: 선형 분류 (ridge)
# ============================================================
#
#   점수 = w1·state8 + w2·state9 + w3·state10 + w4·state11 + b
#   점수 > 0 이면 pattern 1, 아니면 pattern 0
#
#   무게 w는 '연습 문제'의 정답에 가장 잘 맞게 정한다 (최소제곱 + 작은 벌점 LAM).
#   그 전에 연습 문제 기준으로 칸마다 평균 0, 크기 1로 맞춘다 (standardization).
#   시험 문제의 정답은 무게를 정할 때 절대 보지 않는다.
# ============================================================

LAM = 1.0

def fit(F, y):
    mu, sd = F.mean(0), F.std(0) + 1e-12
    A = np.hstack([(F - mu) / sd, np.ones((len(F), 1))])       # 마지막 열 = b
    target = 2.0 * y - 1                                        # 정답 0/1 → −1/+1
    w = np.linalg.solve(A.T @ A + LAM * np.eye(A.shape[1]), A.T @ target)
    return mu, sd, w


def predict(model, F):
    mu, sd, w = model
    A = np.hstack([(F - mu) / sd, np.ones((len(F), 1))])
    return (A @ w > 0).astype(int)


def balanced_accuracy(pred, y):
    """pattern 0 문제와 pattern 1 문제를 따로 채점해서 평균"""
    return np.mean([np.mean(pred[y == c] == c) for c in (0, 1)])


# ============================================================
# 4. 5-fold cross-validation
# ============================================================
#
#   200문제를 다섯 묶음으로 나눈다 (묶음마다 pattern 0·1 반반).
#   묶음 하나를 시험, 나머지 넷을 연습 → 다섯 번 → 점수 다섯 개의 평균.
# ============================================================

def cross_validate(F, y, seed, folds=5):
    rng = np.random.default_rng(seed)
    i0 = rng.permutation(np.where(y == 0)[0])
    i1 = rng.permutation(np.where(y == 1)[0])
    parts = [np.concatenate([i0[f::folds], i1[f::folds]]) for f in range(folds)]
    scores = []
    for f in range(folds):
        test = parts[f]
        train = np.concatenate([parts[g] for g in range(folds) if g != f])
        model = fit(F[train], y[train])
        scores.append(balanced_accuracy(predict(model, F[test]), y[test]))
    return np.mean(scores), np.std(scores)


# ============================================================
# 5. 모형마다 채점
# ============================================================

U, y = make_task(N_TRIALS, SEED)
rng = np.random.default_rng(SEED + 7)
end = slice(8, 12)

def readout_features(X):
    """마지막 4칸 state + 측정기 오차"""
    return X[:, end] + rng.normal(0, NOISE, X[:, end].shape)

models = [("no memory", "-", U)]                                 # state = 지금 입력
models += [("R-C", f"tau = {tau:g}", run_rc(U, tau)) for tau in TAUS]

print("=" * 60)
print(f"readout = last 4 steps, readout noise {NOISE}, chance = 0.50")
print("=" * 60)
print()
print("model      setting     balanced   +/-    label")
print("                       accuracy          shuffle")
print("---------  ---------  ---------  ----  -------")

results = []
for name, setting, X in models:
    F = readout_features(X)
    acc, sd = cross_validate(F, y, SEED)

    # label shuffle: 정답지를 무작위로 섞고 똑같이 → 0.5 근처가 정상 (20번 평균)
    shuffled = np.mean([cross_validate(F, rng.permutation(y), SEED)[0] for _ in range(20)])

    results.append((name, setting, acc, sd, shuffled))
    print(f"{name:<9}  {setting:<9}     {acc:.2f}     {sd:.2f}    {shuffled:.2f}")


# ============================================================
# 6. [그림] τ에 따른 맞힌 비율
# ============================================================

rc = [r for r in results if r[0] == "R-C"]
fig, ax = plt.subplots(figsize=(8, 4.2))
ax.axhline(0.5, color="0.75", lw=1, ls=":", label="chance 0.50 (찍기)")
ax.axhline(results[0][2], color="0.45", ls="--", lw=1.2, label=f"no memory {results[0][2]:.2f}")
ax.errorbar(TAUS, [r[2] for r in rc], yerr=[r[3] for r in rc], fmt="o-", color="#2b59c3",
            lw=2, ms=7, capsize=3, label="R–C (τ마다 한 점)")
ax.set_xscale("log")
ax.set_xticks(TAUS, [f"{t:g}" for t in TAUS])
ax.minorticks_off()
ax.set_ylim(0.4, 1.05)
ax.set_xlabel("R–C time constant τ (칸, 로그 눈금)")
ax.set_ylabel("balanced accuracy")
ax.set_title(f"마지막 4칸 state만 보고 맞힌 비율 (readout noise {NOISE})", loc="left")
fig.tight_layout(rect=(0, 0.08, 1, 1))
fig.legend(*ax.get_legend_handles_labels(), loc="lower center", ncol=3)

plt.show()

코드에서 볼 곳.

  • 3번 상자 fit·predict: 연습 문제로 무게를 정하고(fit), 시험 문제에 그 무게를 곱해 답을 냅니다(predict). 시험 문제의 정답은 무게를 정할 때 절대 보지 않습니다. 보면 시험 문제를 미리 보고 공부한 것과 같아 점수가 부풉니다.
  • 4번 상자 cross_validate: 200문제를 다섯 묶음으로 나눠 넷으로 연습, 하나로 시험을 다섯 번 바꿔 가며 해서 점수 다섯 개의 평균을 냅니다(cross-validation). 표의 +/-는 그 다섯 점수가 서로 얼마나 달랐는지입니다.
  • 5번 상자의 label shuffle: 정답지를 일부러 무작위로 섞고 똑같이 채점하는 점검입니다. 정답이 엉망이니 0.50 근처가 나와야 정상이고, 높게 나오면 코드 어딘가에서 정답이 새고 있다는 경고입니다.
  • readout_features: state를 읽을 때 작은 오차(NOISE = 0.01)를 더합니다. 실제 측정기는 값을 읽을 때 늘 조금씩 흔들리므로 그것을 흉내 냅니다(readout noise).

τ가 너무 짧으면 (0.3칸) 흔적이 다음 칸에서 거의 다 사라집니다. 가운데 칸(4–7)의 큰 입력도 readout 구간(8–11)에 오기 전에 식어 버려서, 두 pattern의 state가 겹칩니다(실습 6, τ = 0.3). 그래도 아주 작은 차이가 남아 0.67로 찍기보다는 조금 낫습니다.

τ가 너무 길면 (100칸) state가 아주 천천히 쌓이기만 해서, 큰 입력이 앞쪽에 왔든 가운데 왔든 "큰 입력 3번의 합"이 같아집니다. 뚝배기가 언제 데워졌는지 모르는 것과 같습니다.

가운데 τ (3–10칸)만 가운데 칸의 흔적은 readout까지 남고, 앞쪽 칸의 흔적은 많이 식어서, 두 pattern이 확실히 달라집니다.

관찰할 점. 흔적이 남는다는 것과 이 과제에 쓸모 있는 흔적은 다릅니다. τ가 과제의 시간 규모와 맞아야 합니다.

과제의 시간 규모: "답을 내는 순간이, 단서가 들어온 순간보다 몇 칸 뒤인가"입니다. 이 과제의 단서는 큰 입력의 위치입니다. pattern 1의 큰 입력(4–7칸)은 readout(8–11칸)보다 1–7칸 앞에 있고, pattern 0의 큰 입력(0–3칸)은 5–11칸 앞에 있습니다. 그러니 약 1–10칸 전의 일을 구별해 기억해야 하고, 그래서 τ = 3–10칸이 가장 잘 맞습니다.

다른 과제도 같은 방법으로 잽니다. 예를 들어 "방금 박동 간격이 그 전보다 짧아졌나"를 판정하려면 한 박동 간격(약 0.8초) 전의 일을 기억해야 하므로, 흔적은 약 1초 정도 남아야 합니다.

R–C 하나도 τ만 맞으면 이 과제를 다 맞힙니다. 그래서 실제 이온 소자가 이 과제를 푼다면 다음 질문은 "R–C 하나보다 무엇이 더 나은가"입니다. P2의 control(비교 대상)이 바로 이 질문입니다.
