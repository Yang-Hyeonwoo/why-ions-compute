30일 질문표

2026년 10월 23일 – 11월 21일

질문은 고정된 것이 아닙니다. '아직 모르는 것' 목록에서 더 좋은 질문이 나오면 바꿔도 됩니다. 날짜가 밀리더라도 질문을 건너뛰지는 않습니다. 상태는 내가 '오늘 학습 완료'를 눌렀는지로 정해집니다.

Phase 1 · 왜 뉴로모픽 컴퓨팅인가

날짜 질문 답에 들어가야 할 것 상태
10/23 (D1) 뉴로모픽 컴퓨팅이란 정확히 무엇이고 기존 컴퓨팅과 무엇이 다른가? 정의, '뉴로모픽'이라는 이름 아래의 서로 다른 줄기(아날로그 VLSI, 디지털 SNN 칩, in-memory computing, 소재 기반 물리 컴퓨팅)와 각각이 푸는 문제, 내가 어느 줄기에 있는지 예정
10/24 (D2) 왜 기존 컴퓨터만으로 충분하지 않은가? 에너지와 시간은 정확히 어디로 가는가? von Neumann 구조, memory wall, 데이터 이동 대 연산 에너지의 자릿수 차이, Dennard scaling 종말 예정
10/25 (D3) 왜 하필 뇌인가? 뇌의 어떤 원리가 실제로 어떤 비용을 줄이는가? "뇌는 20 W"의 비교 함정, co-location·event-driven·analog·시간 동역학·가소성을 비용 절감과 1:1 매핑 예정
10/26 (D4) 뉴로모픽 하드웨어는 실제로 어떻게 계산하는가? crossbar에서 Ohm·Kirchhoff로 하는 VMM, SNN 동작, 시냅스·뉴런 소자에 요구되는 조건(상태 수, 선형성, retention, endurance), 주변회로 비용 예정
10/27 (D5) 뉴로모픽은 어떤 문제에 적합하고 어떤 문제에는 부적합한가? edge, in-sensor, always-on, bio-interface. 진짜 경쟁자는 저전력 MCU + 작은 NN이라는 점 예정
10/28 (D6) 무엇을 해야 '계산한다'고 말할 수 있는가? PPF·STP·LTP 관찰이 곧 유용한 소자인가? 현상 모사와 계산 능력의 구분, 계산이라고 부를 최소 조건. Phase 1 종합: "왜 필요한가" 3문장과 가장 약한 고리 예정

Phase 2 · RC는 왜, 어떻게 작동하는가

날짜 질문 답에 들어가야 할 것 상태
10/29 (D7) RC란 무엇이고 어떤 문제를 풀려고 나왔나? 뉴로모픽과 어떤 관계인가? RNN 학습의 난점(BPTT, gradient 소실·폭주), ESN과 LSM의 탄생 배경 예정
10/30 (D8) 왜 reservoir를 고정하고 readout만 학습해도 되는가? 내부 상태는 무엇을 뜻하는가? x(t+1) = f(W·x(t) + W_in·u(t)), ridge regression, 상태 = 입력 이력의 비선형 전개 예정
10/31 (D9) 왜 memory가 필요하고, fading memory란 무엇인가? echo state property, 전류가 천천히 감소하는 것이 왜 계산에 도움이 되는지의 인과 예정
11/1 (D10) 왜 nonlinearity가 필요한가? 선형계로 못 하는 계산은 무엇이고 high-dimensional mapping·separability는 왜 중요한가? XOR·parity류 과제, 선형 고차원 사상은 여전히 선형이라는 점 예정
11/2 (D11) memory가 길고 nonlinearity가 강할수록 좋은가? memory–nonlinearity trade-off, 총 정보처리용량이 노드 수에 묶인다는 점(IPC) 예정
11/3 (D12) 실습: ESN을 직접 짜서 돌려보면 무엇이 보이는가? NARMA10, memory capacity 측정. 노드 수·spectral radius·leak rate 변화. 입력 지연 탭 + 선형 회귀 baseline과 비교. Phase 2 종합 예정

Phase 3 · 좋은 시스템이란 무엇인가

날짜 질문 답에 들어가야 할 것 상태
11/4 (D13) 좋은 memory란 무엇인가? retention time과 memory capacity는 어떻게 다른가? 감쇠 10 ms 대 10 s 중 어느 쪽이 좋은가는 과제의 시간척도에 달렸다는 점 예정
11/5 (D14) nonlinearity와 state diversity는 어떻게 평가하는가? 큰 응답 변화가 곧 좋은 계산 능력인가? separation·kernel quality·일반화의 구분 예정
11/6 (D15) 왜 MNIST·NARMA·spoken digit을 쓰는가? 각각 무엇을 검증하고 무엇을 검증하지 못하는가? 소자 RC 논문의 MNIST가 시간 과제인지, readout이 일을 다 하고 있지는 않은지 예정
11/7 (D16) 무엇과 비교해야 하는가? 소프트웨어 RC·단순 필터·단순 RC 회로보다 낫다는 걸 어떻게 증명하는가? 적절한 baseline(선형/다항 회귀, NG-RC). "RC 회로로 같은 응답이 나오면 왜 이온 소재인가" 예정
11/8 (D17) 정확도만으로 충분한가? 시스템 전체의 비용은 무엇인가? 소자 수준 energy/op 대 시스템 수준, latency, 입력 인코딩·측정·ADC·readout의 숨은 비용 예정
11/9 (D18) 재현성과 신뢰성은 어떻게 확보하는가? 소자 편차·잡음·장기 안정성은 어디까지 허용되는가? RC에서 편차는 정말 무해한가. Phase 3 종합: 논문 평가 체크리스트 1장 예정

Phase 4 · 왜 이온성 고분자인가

날짜 질문 답에 들어가야 할 것 상태
11/10 (D19) 왜 전자가 아닌 이온인가? 고유한 장점과, 이온이 절대 이길 수 없는 영역은? 이동도·확산계수 자릿수 비교, 다종 carrier, 화학 선택성, 연성·수계 환경 호환 예정
11/11 (D20) 이온 소자에서 memory와 nonlinearity는 어디서 오는가? EDL 충전, 농도 분극·ion depletion, 전기화학 도핑, intercalation, nanofluidic 표면전하, 산화환원. 각각의 휘발성·시간상수·가역성 예정
11/12 (D21) 이온 동역학의 시간척도는 무엇이 결정하는가? 느림은 재료의 성질인가 크기의 문제인가? τ_diff ~ L²/D, EDL 충전 τ ~ λ_D·L/D. L과 D를 바꿔가며 직접 계산 예정
11/13 (D22) 고분자의 화학구조는 계산 특성에 어떻게 영향을 주는가? 사슬 운동성(Tg), 이온–고분자 상호작용, 가교밀도, 이온 농도가 D·τ·비선형성으로 이어지는 경로 예정
11/14 (D23) 이온전도도가 높으면 뉴로모픽 성능도 좋아지는가? conductivity와 계산 성능의 관계. 질문을 "분자구조로 이온 동역학을 어떻게 제어해야 특정 계산 기능이 좋아지는가"로 재구성 예정
11/15 (D24) single-ion conductor·polyelectrolyte·heterojunction은 어떤 고유 이점이 있는가? 일반 ionogel보다 반드시 유리한가? 정류, depletion에서 오는 비선형성, 다중 시간상수가 어떤 계산 primitive가 되는지. Phase 4 종합: 이온 물리 → 계산 primitive 대응표 예정

Phase 5 · 나는 무엇을 연구해야 하는가

날짜 질문 답에 들어가야 할 것 상태
11/16 (D25) 대표적인 이온성 뉴로모픽·RC 논문들은 무엇을 입증했고 무엇을 입증하지 못했는가? 소자 class × 시연 기능 × 지표 × baseline 유무 × 빠진 것의 표. 논문 폴더를 여기에 활용 예정
11/17 (D26) 이온성 RC 실용화의 진짜 병목은 무엇인가? 속도·전력·재현성·집적·안정성·전자회로 인터페이스 중 실제 제약을 계층별로 예정
11/18 (D27) 어떤 문제에서 고분자 이온 소재가 전자·광학 소재보다 경쟁력이 있는가? 응용이 요구하는 사양 대 메커니즘이 허용하는 사양의 교차표. 이 차이가 곧 병목 예정
11/19 (D28) 내가 고분자 설계로 검증할 수 있는 가장 중요한 가설은 무엇인가? 후보 2–3개, 각각 "왜 필요한가"와 "왜 그렇게 되는가"의 사슬 예정
11/20 (D29) 각 후보의 최소 검증 실험은 무엇이고, 성공하면 무엇이 달라지며 실패하면 무엇을 배우는가? baseline, 기각 조건(kill criteria), 새 소자가 꼭 필요한지 예정
11/21 (D30) 결정: 이 연구를 할 가치가 있는가, 좁혀야 하는가, 접어야 하는가? A–E 템플릿으로 연구문제 1개 서술, 또는 접는·좁히는 결론과 그 근거 예정
