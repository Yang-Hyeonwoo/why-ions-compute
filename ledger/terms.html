연구 일반

한국어 English 짧은 설명
용도 application 연구 결과를 실제로 쓰는 곳(예: 심전도 감시 웨어러블).
과제 task 모델이나 소자가 풀어야 하는 구체적 문제(예: 다음 값 예측, 부정맥 분류).
기준선 baseline 새 방법이 이겨야 하는 더 단순한 비교 대상.
재현성 reproducibility 다른 사람·다른 시료로 다시 해도 같은 결과가 나오는 정도.
교란변수 confounder 원인과 결과 둘 다에 영향을 줘 관계를 착각하게 만드는 숨은 요인.
반증 falsification 주장이 틀렸음을 보일 수 있는 실험이나 결과로 검증하는 것.
신뢰구간 confidence interval, CI 참값이 들어 있을 것으로 보는 범위(예: 90 ± 3 %, 95 % 신뢰).
표준오차 standard error 측정 평균이 반복 실험마다 얼마나 흔들리는지 나타낸 값.
벤치마크 benchmark 여러 방법을 같은 조건에서 비교하려고 정해 둔 표준 과제·데이터.
응용 application 연구 결과를 실제 문제에 적용하는 것(예: 웨어러블 심전도 분석).
시스템 경계 system boundary 에너지·지연을 셀 때 어디까지를 포함하는지(소자만, 회로까지, readout과 ADC까지).
허용 오차 tolerance 결과가 받아들여질 수 있는 오차의 허용 범위.
분산 variance 값들이 평균에서 퍼진 정도(편차 제곱의 평균).
원리 증명 proof-of-principle 아이디어가 원리상 작동함을 처음 보이는 단순한 실험.
상관계수 correlation coefficient 두 값이 직선 관계로 함께 변하는 정도(−1~1).
반복성 repeatability 같은 사람·장비·조건에서 반복 측정했을 때 결과가 같은 정도.
결정계수 coefficient of determination, R² 모델이 데이터 변동을 얼마나 설명하는지 나타낸 값(1이면 완벽).
표준편차 standard deviation 값들이 평균에서 퍼진 정도(분산의 제곱근).
절편 intercept 직선 y = ax + b에서 x가 0일 때의 값 b.
원시 입력 raw input 가공하지 않은 측정값 그대로의 입력.
귀속 대조 attribution control 성능이 정말 그 요소 덕분인지 확인하려고 그 요소만 뺀 대조.
민감도 분석 sensitivity analysis 조건을 바꿔 가며 결과가 얼마나 변하는지 살피는 것.
변동계수 coefficient of variation, CV 표준편차를 평균으로 나눈 상대적 퍼짐(예: 5 %).
정규분포 normal distribution 평균 주위에 종 모양으로 퍼진 확률분포.
대조군 control group 처리를 하지 않아 비교 기준이 되는 집단.
확증 편향 confirmation bias 자기 생각에 맞는 증거만 찾고 받아들이는 경향.
실현 가능성 feasibility 주어진 자원·시간 안에 실제로 해낼 수 있는지 여부.
자유도 degrees of freedom 자유롭게 정할 수 있는 독립된 값의 수.
대응 설계 paired design 같은 대상에 두 조건을 모두 적용해 비교하는 설계.
검출력 statistical power 실제 효과가 있을 때 그것을 검출할 확률.
유의수준 significance level 우연을 효과로 잘못 판단할 위험을 허용하는 기준(예: 5 %).
효과 크기 effect size 차이가 실제로 얼마나 큰지 나타낸 값.
무작위화 randomization 조건 배정을 무작위로 해 편향을 막는 것.
사전 등록 preregistration 실험 전에 가설·분석 방법을 미리 기록해 두는 것.
순차 분석 sequential analysis 데이터를 모으는 도중 미리 정한 규칙으로 중간 분석하는 것.
매몰 비용 sunk cost 이미 써서 되돌릴 수 없는 비용. 판단에 넣지 말아야 한다.
존재 증명 existence proof 그런 것이 적어도 하나 존재함을 보이는 증명.

기계학습

한국어 English 짧은 설명
학습 training/learning 데이터로 가중치 같은 매개변수를 맞추는 과정. 이 사이트의 '학습 단위'의 학습(공부)과 다른 뜻.
추론 inference 학습이 끝난 고정 가중치로 새 입력의 답을 계산하는 것.
소자 내 학습 on-chip / in-situ training 컴퓨터 밖에서가 아니라 소자 자체를 직접 바꿔 가며 학습하는 것.
가중치 weight 입력마다 곱하는 중요도 숫자. 소자에서는 전도도로 저장한다.
기울기 gradient 가중치를 조금 바꿀 때 손실이 얼마나 변하는지 나타낸 기울기.
손실 loss 모델 출력이 정답과 얼마나 다른지 나타내는 하나의 숫자.
학습률 learning rate 기울기를 따라 가중치를 한 번에 얼마나 크게 바꿀지 정하는 값.
역전파 backpropagation 출력 오차를 거꾸로 전달해 각 가중치의 기울기를 계산하는 방법.
순환 신경망 recurrent neural network, RNN 이전 시점의 상태를 다시 입력으로 받아 시간 정보를 기억하는 신경망.
스파이킹 신경망 spiking neural network, SNN 뉴런이 연속값 대신 스파이크(펄스)로 신호를 주고받는 신경망.
최소제곱 least squares 예측과 실제 값 차이의 제곱합이 가장 작아지게 맞추는 방법.
과적합 overfitting 학습 데이터는 잘 맞히지만 새 데이터에서는 틀리는 현상.
일반화 generalization 학습에 쓰지 않은 새 데이터에서도 잘 맞히는 능력.
분류 classification 입력을 정해진 종류 중 하나로 나누는 과제(예: 정상/부정맥).
선형 분리 linear separability 두 종류의 점들을 직선(평면) 하나로 나눌 수 있는 성질.
선형 회귀 linear regression 입력의 가중합(직선)으로 출력 값을 예측하는 방법.
혼동 행렬 confusion matrix 정답 종류별로 예측이 어디로 갔는지 세어 놓은 표.
로지스틱 회귀 logistic regression 가중합을 0–1 확률로 바꿔 두 종류를 나누는 분류 방법.
순전파 forward pass 입력에서 출력 쪽으로 차례로 계산해 예측값을 얻는 것.
연쇄 법칙 chain rule 합성함수의 미분을 각 단계 미분의 곱으로 구하는 규칙.
가중치 공유 weight sharing 여러 곳에서 같은 가중치 값을 함께 쓰는 것.
표현력 expressive power 모델이 얼마나 복잡한 입력–출력 관계를 나타낼 수 있는지.
전치 transpose 행렬의 행과 열을 맞바꾸는 것.
역행렬 inverse matrix 곱하면 단위행렬이 되는, 행렬의 '나눗셈' 역할을 하는 행렬.
규제항 regularization term 가중치가 너무 커지지 않게 손실에 더하는 벌점 항.
교차 엔트로피 cross-entropy 예측 확률이 정답에서 얼마나 먼지 재는 분류용 손실.
원-핫 one-hot 정답 칸만 1이고 나머지는 0인 벡터(예: [0,1,0]).
검증 데이터 validation data 학습 중 설정값을 고르려고 따로 떼어 둔 데이터.

정답률 accuracy 전체 중 맞힌 비율(accuracy).

함수율 water content 재료가 머금은 물의 비율.

폴리전해질 polyelectrolyte 사슬에 전하 띤 기가 반복해 붙은 고분자(예: PSS).
